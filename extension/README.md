# LockNotch Chrome Extension

Extensión ultra-ligera en Manifest V3 para transmitir el progreso y velocidad de tus descargas en tiempo real a la Dynamic Island de LockNotch.

## Instalación en 3 pasos:

1. Abre Google Chrome (o Edge / Brave) y ve a:
   `chrome://extensions/`
2. Activa el interruptor **Modo de desarrollador** (arriba a la derecha).
3. Haz clic en el botón **Cargar descomprimida** (Load unpacked) y selecciona esta carpeta:
   `C:\Users\vCesar\OneDrive\Escritorio\Proyectos\LockNotch\extension`

¡Listo! Cuando descargues cualquier archivo, LockNotch cambiará automáticamente al modo de descarga mostrando el nombre, porcentaje y velocidad en tiempo real.
